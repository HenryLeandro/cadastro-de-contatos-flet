# Cadastro de Contatos

Aplicativo de cadastro de contatos desenvolvido em Python utilizando Flet.

## Funcionalidades

- Adicionar contatos
- Editar contatos
- Excluir contatos
- Salvar contatos em arquivo JSON
- Interface gráfica utilizando Flet

## Tecnologias

- Python
- Flet
- JSON
